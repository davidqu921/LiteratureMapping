AAAI-27 extended abstract: local project and reproducibility
========================================================

Start here
  main.pdf              Compiled anonymous manuscript, four pages total.
  main.tex              One LaTeX source; one summary table and one heatmap.
  figures/behavior_outcomes.pdf       Main-text vector heatmap (Figure 1).
  figures/evaluator_behaviors.pdf     Companion evaluator/behavior heatmap.
  figures/evaluator_outcomes.pdf      Companion evaluator/outcome heatmap.
  references.bib        31 corpus DOI records plus one external background item.
  aaai2027.sty/.bst     Unmodified official AAAI-27 files.
  overleaf_source.zip   Minimal editable Overleaf project with offline analysis.
  ../docs/EVIDENCE_AUDIT.md  English evidence and requirements audit (repository).

Compile in Overleaf
  Upload overleaf_source.zip as a new project. Select main.tex as main file,
  PDFLaTeX as compiler, and current TeX Live. Recompile normally.
  No Python execution, shell escape, or network fetch is needed to compile.
  The table is inline; the vector figure PDFs are bundled.

Compile locally
  python build.py
  Or: python build.py --tex-bin <directory-containing-pdflatex-and-bibtex>
  For page checks/rendering, install PyMuPDF in your chosen Python environment
  and add --verify. The normal build requires only Python's standard library
  and a TeX distribution with the official template dependencies (notably
  newtx, helvet, courier, natbib, caption, booktabs).
  After changing analysis data, run build.py --refresh-figures; this additionally
  needs PyMuPDF and LaTeX standalone, tabularx, array, and xcolor. A fingerprint
  check prevents compiling stale heatmaps after an analysis change.

Equivalent TeX commands, from this directory
  pdflatex -interaction=nonstopmode -halt-on-error main.tex
  bibtex main
  pdflatex -interaction=nonstopmode -halt-on-error main.tex
  pdflatex -interaction=nonstopmode -halt-on-error main.tex
  The style sets the bibliography style automatically. Do not add a second
  bibliographystyle command. Do not alter template geometry or font sizes.

Frozen input structure
  data/final_map.csv is an exact copy of the project's FINAL MAP CSV.
  UTF-8 CSV; 17 columns; row 1 group labels, row 2 attribute names, row 3
  definitions; rows 4 onward publication records. Columns A-C: URL/title/DOI.
  D: empty separator. E-G: evaluator; H-L: behavior; M-Q: outcomes.
  X means marked. Empty means unmarked, not confirmed absent or N/A.
  DOI is the counting key; multiple attributes per publication are allowed.
  Unexpected values, duplicate DOI keys, or None plus another outcome fail.

Recalculate tables and statistics
  python analyze.py
  Produces generated/analysis.json, codebook.csv, coded_records.csv,
  outcomes.tex and matrix.tex. Replaces only the two GENERATED display blocks
  in main.tex. Interpretive prose and the evidence audit must be reviewed manually
  if input data change; numeric findings in prose are not auto-rewritten.
  Main statistics retain all 31 records. A separate sensitivity removes two
  explicitly identified reviews. Neither operation changes manual labels.

Vector heatmaps
  python export_heatmaps.py --tex-bin <directory-containing-pdflatex>
  Re-typesets the original 55 intersections and purple=count/N shading using
  10-pt embedded Type 1 fonts. The old main_heatmaps.pdf uses Type 3 fonts;
  it is preserved unchanged, rather than embedded in the AAAI manuscript.
  Cell values extracted from all three new PDFs are checked against statistics.
  figures/provenance.json records hashes, original panel numbers, and checks.
  The behavior/outcome panel replaces the old cross-tabulation in the main
  paper; the two evaluator panels are companion assets, not duplicate displays
  in the four-page manuscript. Their three-row schema preserves FINAL MAP;
  it does not include general-human/student columns from Mapping Discrepancies.

Additional local audits (original repository required)
  python audit_workbook.py
  Reads ../data/lit-map 2026s sycophancy.xlsx and checks FINAL MAP, prior mapping
  fields, screening snapshots, duplicates, and the two omitted evaluator
  columns. An explicit workbook path can be supplied. It reads cached values;
  it does not execute Excel formulas or treat edited A/B values as initial IRR.

  python audit_metadata.py
  Reads ../output/final_map/crossref_cache offline and creates corpus_manifest
  and metadata_audit outputs. No paid API or network query is involved.

  python verify.py
  Requires PyMuPDF. Checks page count, citations, typography, rendered bounds,
  generated displays, all 55 cells in the three new vector PDFs, and (when
  present) the old 55 heatmap cells and downloaded
  official template. Creates qa/validation.json and four page PNGs.
  Human visual inspection remains necessary.

Evidence boundaries
  evidence/study_audit.json separates original labels from new extraction and
  proposed corrections. evidence/sources retains public author PDFs and
  retrieval provenance for local audit. ACM PDF failures are recorded, not
  bypassed. Older friendly/advice versions are retained as retrieval history;
  the manuscript uses friendly_v3.pdf and advice_v2.pdf, not the older files.
  fetch_sources.py is optional, network-dependent, and never part of a build.
  It fetches public resources, with size limits and one-second request spacing.

Sharing
  overleaf_source.zip contains the manuscript, frozen analysis input and
  necessary build scripts. It excludes local full-text PDFs, workbook/coder
  identities, browser downloads, and working notes. No project has been
  uploaded or submitted externally by this task.
