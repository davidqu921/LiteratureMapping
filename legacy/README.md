# Historical table artifacts

`original_tables/` preserves the earlier example table fragments, LaTeX file, and PDF, formerly stored in `files/`. They are retained for design history and are not outputs of the current sycophancy analysis.

The old LaTeX file references table names and a bibliography that were not supplied, and uses a poster layout. Use the current generator under `scripts/` and configurations under `configs/` for a complete build. The manuscript project is in `paper/`.
